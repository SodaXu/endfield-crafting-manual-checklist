## Current hero: 祀 / Si

- Source file page: https://endfield.wiki.gg/wiki/File:Si_Splash_Art.png
- Original image URL resolved from that page's original-file link: https://endfield.wiki.gg/images/Si_Splash_Art.png?fe694e
- Retrieved and checked: 2026-10-23. Command-line requests received HTTP 403; Chrome successfully loaded the actual file page (HTTP 200) and its image. No substitute artwork was used.
- Downloaded image: 2048 × 2048 pixels, RGBA PNG, 4,970,372 bytes. The wiki page describes the current revision as 2048 × 2048, uploaded 2026-10-15; its displayed file-size figure was 5.54 MB, which differs from the response downloaded here.
- Local optimized file: `si-splash.webp`, 1600 × 1600 pixels, 747,224 bytes; Pillow Lanczos resize, WebP quality 87, method 6. Alpha transparency retained. No crop, recoloring, or compositing into the source image.
- Display: full square artwork with `object-fit: contain`, over a dark radial-gradient backing. Desktop copy and art occupy separate columns; mobile stacks copy above the complete image. No overlaid text or gradient obscures the character's face. The page loads only the local image.
- Attribution is visible in the on-page “实用工具与 Wiki” module and the data-info dialog.

## Design reference

- Reference site: https://endfield.gryphline.com/en-us#home
- The official site informed the yellow `#fffa00`, black / light-gray contrast, uppercase display type, thin technical rules, bracket markers, diagonal hatch accents, rectangular controls, and side navigation.
- This handbook uses local system fonts and its own unofficial text identity, not the official logo or proprietary fonts. No new dependency, remote font, or video is used.
